# HairByJay

A small business website for HairByJay which focuses on selling luxury lace wigs and hair pieces. Built around the brand's motto: *"Wear luxury, not effort."*

## About the business
HairByJay is a South African hair brand based in Johannesburg, Sandton which offers a hand picked collection of 100% human hair lace wigs. Each and every piece is chosen for its quality, density, natural shine and a pre-plucked hairline built for women who want salon experience along with quality hair without the salon long hours.

## Tech Stack
- HTML5
- CSS3 (custom stylesheet, no framework)
- Google Fonts — Playfair Display (headings) & Jost (body text)

## Running Locally
No build tools or dependencies required.

1. Clone or download this repository
2. Open `index.html` in any web browser

The whole site is static HTML and CSS.

## Pages
- **Home** — Hero section, tagline, featured products, and brand highlights
- **About Us** — Brand story and core values
- **Products** — Full product grid with images and pricing
- **Contact Us** — Location details and embedded Google Map
- **Enquiries** — Embedded Google Form for customer enquiries

## Design
Colors and typography are drawn directly from the HairByJay brand mark:
- Blush pink, deep wine, warm cream, and gold accents
- Playfair Display for an elegant, editorial feel
- Jost for clean, readable body text
